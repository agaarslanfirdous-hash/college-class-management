# Administrator quick guide

1. **Sign in** as admin.
2. **Departments / Classes / Schedules** — build the academic structure.
3. **Assignments** — offer each schedule to a teacher; assign an optional class monitor.
4. **Enrollments** — link students to classes (needed for student timetable).
5. **Rejections** — respond to teacher decline explanations.
6. **Attendance** — review daily records; **Reports** export CSV for compliance.
7. **Audit log** — trace sensitive actions.
8. **Settings** — CSV bulk import; configure server cron for reminders.
